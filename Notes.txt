***Search Script***
******************************************

Search for any target:

.\seti-python.bat src\bl_search.py --find proxima

Get files for a target:

.\seti-python.bat src\bl_search.py --target PROXCEN --telescope Parkes --cadence

Download files:

.\seti-python.bat src\bl_search.py --target PROXCEN --cadence --download data/ --n 2

The API docs are at docs/bl_api_reference.md with every endpoint, parameter, filename convention, and target name mapping documented. Next time you ask for data on a target, I can query the API directly instead of fighting that broken portal.

usage: bl_doppler_search.py [-h] [--out OUT] [--min-drift MIN_DRIFT] [--max-drift MAX_DRIFT][--snr SNR]
filepath

turbo_seti Doppler drift search.

positional arguments:
  filepath              Path to .fil or .h5 file

options:
  -h, --help            show this help message and exit
  --out OUT, -o OUT     Output directory
  --min-drift MIN_DRIFT
                        Min drift rate (Hz/s)
  --max-drift MAX_DRIFT
                        Max drift rate (Hz/s)
  --snr SNR             SNR threshold

The script outputs:
• RFI (rejected): Appears in both ON and OFF = terrestrial
• Candidates: Appears in all 3 ON, zero OFF = interesting
• Transient: In some ON but not all, not in OFF = likely transient RFI
• OFF only: Reference noise

A frequency/SNR scatter plot gets saved showing green stars for candidates, red X's for rejected RFI.

Step 1: Run Doppler search on all 6 files

.\seti-python.bat src\bl_doppler_search.py data\Parkes_57910_34684_PROXCEN_S_mid.h5 --out results
.\seti-python.bat src\bl_doppler_search.py data\Parkes_57910_35032_PROXCEN_R_mid.h5 --out results

.\seti-python.bat src\bl_doppler_search.py data\Parkes_57910_36390_PROXCEN_R_mid.h5 --out results

Step 2: RFI rejection (all 6 files at once)

.\seti-python.bat src\bl_rfi_reject.py --on results\Parkes_57910_34684_PROXCEN_S_mid.dat results\Parkes_57910_35370_PROXCEN_S_mid.dat results\Parkes_57910_36052_PROXCEN_S_mid.dat --off results\Parkes_57910_35032_PROXCEN_R_mid.dat results\Parkes_57910_35708_PROXCEN_R_mid.dat results\Parkes_57910_36390_PROXCEN_R_mid.dat --plot --save-plot results\proxima_rfi_rejection.png

The script categorizes every hit into four buckets:

• RFI (rejected): Appears in both ON and OFF = terrestrial
• Candidates: Appears in all 3 ON, zero OFF = interesting
• Transient: In some ON but not all, not in OFF = likely transient RFI
• OFF only: Reference noise
