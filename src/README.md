# src/ - Analysis Scripts

Scripts for processing Breakthrough Listen data.

## Planned Scripts

- `bl_inspect.py` - Load and inspect a BL data file (waterfall plot, header info)
- `bl_doppler_search.py` - Run turbo_seti FindDoppler on a target file
- `bl_rfi_reject.py` - On/off cadence RFI rejection
- `bl_batch.py` - Batch process multiple observations
